# 图片承担正文时，怎样分析作者风格

本方法供首次建库、增量分析和模型复核使用。图片承担观点、对白、情节或论据时，图片就是正文的一部分。
首次建库全量阅读；模型完成后的日常创作只加载已保存风格，不再次读取原文章、原图、文章卡片或全量索引。
用户明确要求补充资料或更新风格时，才阅读新增、变更资料及受影响证据；不把本方法变成每次写作的前置步骤。
适用于漫画、照片叙事、知识图卡、信息图、截图解说及混合形式；不能把某个漫画账号的固定人物或颜色写成所有账号的规则。
联合记录、来源绑定和创作产物的契约见 [visual-style.md](visual-style.md)。

## 全量阅读与分析单位

首次分析先逐篇阅读全部纳入文章的图外文字和全部正文图片，为每篇建立简洁分析，再选择代表样本深析。
抽样决定分析深度，不决定哪些文章可以不读。不能把扫描、OCR、生成联系表或导入成功计为已阅读。
可分批保存进度，但不得在仍有未读文章时把抽样模型称为全库结论。

分析分四层：单图表达 → 完整文章的图文组织 → 同主题写法 → 跨主题、跨时期稳定风格。
理解整篇时保留原始图片顺序、图外段落的穿插位置和最终收尾；不把一张图单独算作一篇文章。
重复图片可复用视觉观察，但在新文章中的位置、搭配文字和作用须重新判断。

先判断每篇是文字为主、图文共同承担正文，还是图片承担主要正文。判断依据是信息由谁承担，不能只看图片数量。
Markdown没有提取到图片，不足以证明文章是纯文字：若HTML含轮播、长图或图片内容容器，需核对实际载体是否漏提取。
缺图、图片不清、说话者不明或正文容器为空时保留具体待处理项，不用标题或相似文章补写缺失内容。

## 先区分素材角色

分别记录封面、正文图片、论据截图、身份横幅、装饰、广告和平台元素。角色按实际用途判断：
截图可能是核心论据；小动画可能只是分隔；身份横幅不计作观点卡。底层联合记录的 role 仍按 visual-style.md 契约填写，
例如承担正文论据的截图属于 body；封面证据单独保存，不把未出现在正文中的封面硬加进 units。

分别统计文章数、图片引用数、不同图片数、正文图数、内容条目数、对照组数与封面数。
一个对照组可能需要两张卡，一张长图也可能含多个分格。记录真实阅读顺序，不从文件名排序推断。
动画先看完整帧序列再判断角色；透明图在实际展示底色或明确注明的白底上查看，避免把透明区域误认成黑色背景。

## 单图观察维度

每张正文图都记录可读文字、关键画面事实及二者共同表达的意思。下表用于查漏，不要求逐图机械填满相同长表；
没有人物、对白或标题时明确不适用，不编造不存在的元素。关键细节不清楚时查看原尺寸。

| 维度 | 要观察的内容 | 转成创作规则时要回答的问题 |
| --- | --- | --- |
| 信息任务 | 该图在提出观点、举例、解释、比较、证明、转折还是收尾；承载几个信息点 | 一张图应讲多少，画面和文字怎样分工 |
| 图片文字 | 标题、标签、解释、旁白、对白、内心话；句式、口语、反问、强断言、字数与断行 | 哪些话适合做标题，哪些应由人物说或留在图外 |
| 声音归属 | 谁在说、对谁说、谁在想；气泡尾巴、思考连接、裸文字与多人的读序 | 如何避免旁白冒充对白、内心话被说出口、气泡指错人 |
| 人物与对象 | 单人、双人、亲子、群像；年龄感、比例、服装、表情、姿态、视线、身份辨识 | 哪些特征应单篇一致，哪些随主题、职业或阶段改变 |
| 动作、道具与关系 | 谁主动、谁回应；拿什么、做什么；远近、朝向、接触、遮挡、权力与注意力分配 | 如何把抽象观点变成具体可见场景，删去哪个细节会改变意思 |
| 画风与质感 | 漫画、写实摄影、拼贴等；人物比例、线条粗细、平涂/渐变/排线、颗粒、光影、色彩范围 | 应保留哪些视觉倾向，不能只写“高级、治愈、漫画风” |
| 文字视觉 | 字形类别、粗细、层级、对齐、行距、颜色、气泡和文字区 | 手机端先看什么、后看什么；无法确认的字体名不猜测 |
| 构图与空间 | 画幅、景别、视角、人物落点、焦点、前后景、留白、背景详略、文字与画面占位 | 同篇怎样统一识别感，同时变化镜头；留白是版式还是叙事距离 |
| 证据表达 | 照片、截图、图表如何支持观点；图表尺度、标注、出处与裁切上下文 | 哪些是作者的解释，哪些有画面或来源支持；图中数据不自动当成事实 |
| 图文关系 | 相互说明、互补、对照、反讽、因果演示，或存在矛盾 | 文字与画面一起才成立的意思是什么 |

图文关系至少回答：图中文字说什么；画面额外告诉读者什么；结合起来读者接受什么判断；
只留下文字会丢失什么。不能只分别列“文案口语化”和“配图淡彩”，却没有联合结论。
关键文字与说话者必须核对；逐字引句与观察转述分开记录，不能把转述放进引号冒充原句。

## 整组图片怎样形成文章

为每篇说明开场、相邻图关系、转折、末图功能和图外文字作用。以下是可选结构，不是固定模板：

| 组织方式 | 阅读时核对 |
| --- | --- |
| 并列清单 | 每点是否不同、是否可独立理解；不能凭编号虚构时间推进 |
| 档位或梯度比较 | 比较轴和排序方向；每档改变什么；情绪与数字是否同向；是否有末图反转 |
| 成对对照 | A/B是否比较同一件事；交替、分屏还是分组排列；组数与图数是否不同 |
| 时间叙事或人生阶段 | 人物、场景、关系怎样连续变化；文字是否真的支持因果解释 |
| 步骤教程或信息解释 | 前后是否有操作依赖；每步的输入、动作、结果怎样呈现 |
| 照片、截图或图表论证 | 图片与观点的对应关系；裁切、标注、前后上下文是否影响结论 |

同时观察重复与变化：人物、标题、配色怎样保持识别感，景别、动作、道具和信息密度怎样调节节奏。
明确有无独立开场卡、总结卡。不能因为末图不总结，就忽略图外结尾对全篇立场的修正。
图外文字可能承担引入、穿插解释、情绪转向、边界说明或互动；也可能没有，不预设固定字数。

## 封面与正文分别分析

封面看标题钩子、场景组合、人物数量、裁切、焦点与正文呼应；正文看连续阅读与信息展开。
不能把封面的横幅比例直接套到正文卡，也不能未经查看就推断空白是为平台叠字预留。
封面尚未读取时，单独标明覆盖情况；不从少量封面概括全库。

## 从观察提炼可执行规则

同主题文章先比较表达任务、视觉例子、声音角色、整组结构和收尾，再跨主题、跨时期验证。
画风、版式、人物设定、组图组织分别建模；编号相同不能证明画风相同，人物相似不能证明所有主题都用同一角色。
区分全局稳定、主题适应、时期变化、系列习惯与单篇特征，保留反例和未覆盖范围。

每条规则包含：规则内容、文章ID及图片序号/哈希、可见证据、适用主题与时期、稳定程度、执行方法、反例或边界。
图数、字数、比例与留白的精确范围来自已核对样本的实际测量；没有测量时只作定性描述。
不根据发布时间、画面气质或AI声明推断作者身份、具体字体、生成工具、创作意图或传播效果。

执行方法应能指导：新观点 → 结构选择 → 单图文字角色 → 动作/对象/关系或信息示意 → 构图与画风 → 相邻图承接。
例如表达“分担家务”，应描述两人的分工、动作及由此形成的关系，而不是只要求一个人微笑站立。
对无人物的信息图，应解释如何用层级、箭头或对照支持结论，不强行添加漫画角色。
模型要让未见原图的创作会话知道怎样写和画；“照原图”“保持同款感觉”不是完整规则。

## 交付和状态

逐篇卡片可简洁保存；详细图片事实与联合结论保存到正式联合记录，模型引用证据，无需复制成多份长报告。
主题模型包含图文适配，全局图文模型只保留经跨样本验证的规则。分别记录图外文字量、单图文字量、
整组文字量、正文图数和对照组数，不把OCR总字数当成外置长文目标。

图片正文账号的后续成品应保留已学到的表达载体。用户要求完整文章时，只有散文或生图提示词仍不算图片正文完成；
用户明确只要文案时按其要求交付。实际图片逐图核对文字、声音归属、关键动作、图文意思、顺序、一致性与身份过滤。

最终分别报告：纳入文章数、完整读完数、缺失/未读数、已看正文图片数、封面覆盖、代表深析样本数和模型验收状态。
文件生成或结构校验成功不证明语义分析完成；未读文章和未解决的关键图文疑点继续保留待处理。
